# Szakvizsga 
*mark & erik prod.*

This project is a Python-based job board and recruiting application built with an object-oriented architecture and a PySimpleGUI interface. 

It features two distinct user roles: 
- **Admins** can manage job postings and track applicants.
- **Applicants** can browse open positions, apply with their CV, and filter for high-paying roles based on experience. 

The codebase is cleanly divided into data models (`entities.py`), business logic (`service.py`), and the graphical user interface (`ui.py`).
